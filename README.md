# 🔥 VALAK – Evil Twin Attack Framework for ESP32 (Arduino IDE)

**VALAK** هي أداة اختبار اختراق أخلاقي متخصصة تعتمد على وحدة **ESP32**. تقوم بتنفيذ هجوم **التوأم الشرير (Evil Twin)** الحقيقي عن طريق إنشاء نسخة متطابقة من شبكة Wi-Fi موجودة، مع عرض صفحة تصيد احترافية. تم تصميمها لأغراض تعليمية واختبار أمان الشبكات اللاسلكية في بيئات مرخصة.

## ✨ الميزات

- 🕸️ **إنشاء شبكة Evil Twin** باسم `Justicar` (SSID مطابق للشبكة المستهدفة).
- 🔐 **كلمة مرور الشبكة المزيفة** `48522844` (قابلة للتعديل).
- 📡 **صفحة تصيد احترافية** تعرض على الضحية عند محاولة الاتصال بالشبكة.
- 🖥️ **لوحة تحكم (Dashboard)** لعرض البيانات المسروقة:
  - عنوان IP
  - البريد الإلكتروني المسجل
  - كلمة المرور المدخلة
  - نوع الجهاز
  - المتصفح
  - الموقع الجغرافي التقريبي (إن أمكن)
- 🔑 **تسجيل الدخول إلى لوحة التحكم**:
  - **العنوان:** `http://192.168.1.4`
  - **اسم المستخدم:** `admin`
  - **كلمة المرور:** `48522844`
- 💻 **يعمل على ESP32** ببرمجة عبر **Arduino IDE** (لا يحتاج إلى كمبيوتر بعد الرفع).
- 🔋 **مستقل** – يشغل نفسه بمجرد توصيل الطاقة.

## 📦 المتطلبات

- **وحدة ESP32** (NodeMCU-32S، WROOM، Lolin32، إلخ).
- **سلك USB** لبرمجة الجهاز.
- **Arduino IDE** مثبتة على جهازك (Windows، Linux، macOS).
- **حزمة ESP32** في Arduino IDE.
